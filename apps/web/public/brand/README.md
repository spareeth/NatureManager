# Brand logos

Put the official logo files here (Terra, Expo City Dubai style guide, "Logos and partner branding").
Do not redraw, recolour or crop them. Minimum digital size 50 px wide.

| File | Use |
| --- | --- |
| `terra-white.png` | Terra wordmark, white: app header (forest ground) |
| `ecd-white.png` | Expo City Dubai logo, white: app header |
| `terra-colour.png` | Terra wordmark, colour: sign-in page (white ground) |
| `ecd-colour.png` | Expo City Dubai logo, colour: sign-in page |

The style guide says the official files are in the Global Water Investment Atlas repository under
`web/public/brand/logos`. Until they are added, the app shows the names as text.

Sources (official artwork, not redrawn): the white files are from the Terra Impact web kit
(`assets/logos/terra-wordmark-white.png`, `expo-city-dubai-white.png`); the colour files are `terra logo_rgb.png`
and `EXPO_CITY_DUBAI_LOGO_DUAL_HORIZONTAL_BLACK.png`, scaled to 400 and 600 px wide.
